# 原项目与 React SPA 业务对照

本表按原静态项目实际可用的交互和数据规则复核。没有新增产品规则；“路由改造”和“登录/注册拆分”是本次明确要求的结构调整。

| 业务域       | 原项目行为                                              | React SPA 结果                                            | 结论                             |
| ------------ | ------------------------------------------------------- | --------------------------------------------------------- | -------------------------------- |
| 入口与导航   | 多个 `.html` 页面、个人中心使用 hash 标签               | 单一 `index.html`，公开页和 `/center/:tab` 由路由系统管理 | 入口结构按要求改变，页面含义不变 |
| 路由鉴权     | 未登录访问个人中心跳登录，成功后返回                    | 路由守卫统一处理并保留目标地址                            | 一致                             |
| 登录与开户   | 同一表单按邮箱存在与否登录或隐式开户                    | `/login` 只登录，`/register` 明确注册，成功后返回目标     | 按要求完善；账号校验规则不变     |
| 邀请码       | 主邀请码 `DC-199476`，或已注册用户的个人邀请码          | 注册时执行同一有效性校验并记录 `usedInviteCode`           | 一致                             |
| 首页提交     | 最少 10 字、一次一件事、可公开；游客登录后续提          | 同样校验；待提交内容由 session Storage 适配器恢复         | 一致                             |
| 新想法与迭代 | 新想法可独立提交；迭代必须绑定原想法                    | 数据结构、初始“待评估”状态和父级关系不变                  | 一致                             |
| 公开想法     | 只展示公开的新想法，支持搜索、排序、登录点赞            | 展示范围及点赞/取消点赞规则不变                           | 一致                             |
| 案例         | 只展示“已完成”的新想法                                  | 筛选规则不变                                              | 一致                             |
| 管理员评估   | 1—3 级免费进入排队；4—6 级设置费用后待付款；可不制作    | 评级、费用、状态、通知流程不变                            | 一致                             |
| 余额与付款   | 充值 1—99999 元；想法、套餐和押金使用站内余额           | 金额限制、扣款、交易记录和余额不足提示不变                | 一致                             |
| 套餐         | 25 元与 99 元，30 天；配额分别为 2/4、2/15；同套餐顺延  | 价格、有效期、配额、续费和不自动扣款规则不变              | 一致                             |
| 团队申请     | 负责内容、时间和不超过 20 MB 的 PDF；可撤回、下载、审核 | 表单流程不变；文件改由 Java 服务保存并校验归属            | 一致                             |
| 反馈         | 游客/用户可提交三类反馈，用户与管理员持续回复并结束     | 会话、状态流转和通知不变；页面来源继续保存兼容旧名称      | 一致                             |
| 通知         | 想法、付款、套餐、反馈、合作通知；筛选、未读、全部已读  | 规则不变；新链接改为 SPA 路由并兼容已有 hash 链接         | 一致                             |
| 商务合作     | 2000 元押金，付款后展示邮箱，结束后全额退回             | 扣款、展示、状态和退款不变                                | 一致                             |
| 管理员审计   | 管理操作入审计，最多 500 条                             | 数据结构与上限不变                                        | 一致                             |
| 动态数据     | 页面脚本直接操作本地业务数据                            | 页面统一调用 Java HTTP API，业务数据持久化到 MySQL        | 按要求改造，业务模型不变         |

原页面中未接入实际流程的孤立 DOM/死代码不作为业务功能迁入；其余可操作业务均已对应到 React 页面或 feature 模块。
