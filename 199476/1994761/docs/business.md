## 想法

- 想法分为“新想法”和属于某个新想法的“后续迭代”。
- 新记录初始状态为“待评估”；公开的新想法会进入用户想法列表。
- 登录用户可点赞或取消点赞，可把自己的新想法设为公开或私密。
- 管理员在 1—6 级内评级并决定是否制作：
  - 不制作：进入“不制作”。
  - 1—3 级制作：无需单独付款，进入“排队中”。
  - 4—6 级制作：填写费用，进入“待付款”。
- 付费想法仅使用站内余额支付，付款后进入“排队中”。
- 制作状态按“待评估 → 待付款/排队中/不制作 → 制作中 → 已完成”单向流转；待付款记录也可由管理员终止为“不制作”。已评估记录不能重复评估。

## 余额与套餐

- 余额通过页面中的支付宝确认流程充值，充值金额限制为 1—99999 元。
- 站内余额用于想法费用、套餐和商务合作押金。
- 标准套餐：25 元/30 天，2 个微型项目、4 次迭代。
- 升级套餐：99 元/30 天，2 个小型项目、15 次迭代。
- 相同有效套餐续费时，从当前到期日顺延并累加权益；不自动续费。

## 团队申请与文件

- 加入我们指成为长期合作者。
- 申请需填写负责内容、可投入时间，并上传 20 MB 以内 PDF 简历。
- 简历由 Java 服务保存并在 MySQL 中记录文件元数据；文件只能由所属用户或管理员下载，用户可撤回，管理员可审核状态。

## 反馈、通知与审计

- 游客和登录用户均可提交“功能问题、使用问题、建议”。
- 反馈是可持续回复的会话，状态为“待管理员回复、待用户回复、已结束”。
- 想法进度、待付款、套餐、反馈和商务合作会生成站内通知，支持未读、分类筛选和全部已读。
- 管理员操作写入审计记录，最多保留 500 条。

## 商务合作

- 中大型、深度定制或长期合作通过商务合作入口处理。
- 支付 2000 元站内余额押金后显示联系邮箱。
- 管理员可标记已联系；沟通结束后押金全额退回站内余额。

## 展示页面

- 用户想法页仅展示公开的新想法。
- 案例页仅展示公开且状态为“已完成”的新想法，登录后也不会把自己的私密想法带入公共案例页。
- 服务规则页保留用户协议、隐私、退款、套餐权益与交付标准。
