## 5. 已确认问题

### P0：按经历找人无法返回已关联用户

- 复现：B 完成实名和岗位认证 → 新增经历 → 后台建立标准经历 → 审核时关联标准经历 → 个人卡片已显示经历 → 打开“按经历找人”。
- 实际结果：页面显示“暂无数据”，公开接口 `/api/public/discovery/experiences/search` 返回空数组。
- 数据核对：标准经历存在且启用，认证记录为 `APPROVED`、`enabled=true`、未删除，B 为 ACTIVE 且接受新询问，实名和岗位均已通过。
- 定位：公开经历查询把用户资格的相关子查询写在 `LEFT JOIN users` 的连接条件中；当前 MySQL 9.1 下该查询计算出的人员数量为 0，而拆开查询时身份、岗位和经历关系均为 1。
- 影响：按经历找人核心入口不可用。

### P1：首次隐私提示仍使用旧平台名称

- 当前弹窗正文出现“欢迎来到光忆”“光忆APP”等文字。
- 当前 App 名称是“事先问”，发布前需要统一。

### P1：登录页协议区域在当前真机上被底部裁切

- 在 BON-AL00 上关闭键盘后，协议勾选和协议文字贴近窗口最底部，可访问区域高度被压缩，存在误触和不同系统导航模式下不可操作的风险。
- 键盘弹起时该区域能完整显示，说明是底部安全区/页面高度适配问题。

### P2：商务合作可重复提交相同内容

- 提交成功后输入内容未清空，也没有页面级已提交状态。
- 再次点击会新增一条相同记录，本次数据库中已有 2 条可复现数据。
