# elephant_cross 第三方能力迁移记录

本文件记录 `D:\Harvey\elephant_cross` 中与“事先问”移动端相关的第三方能力，避免后续维护时再次重复排查。

## 已复用

- 支付宝标识：复用 `font_awesome_flutter` 的支付宝品牌图标，不再使用文字模拟图标。
- 支付宝拉起兼容：Android 已声明支付宝 URL Scheme 的应用可见性。
- 外部支付页：继续使用 `url_launcher` 打开后端返回的支付宝支付地址。
- 图片选择、视频播放、安全令牌存储、WebSocket：当前项目已经有对应实现，版本和结构均比旧项目更适合当前业务，不重复引入。

## 没有直接迁移

- 旧项目 API、WebSocket 地址：它们属于旧系统，不能连接到“事先问”后端。
- 旧应用包名、签名文件、Deep Link Scheme：它们与已上线旧应用身份绑定，复制后会造成安装、支付回跳或商店签名冲突。
- 高德地图 Key、定位权限：当前项目没有定位业务；同时不应把服务密钥继续硬编码在移动端。
- 极光 Master Secret：服务端密钥不能放在移动端，而且当前项目没有使用极光消息服务。
- `tobias` 原生支付宝 SDK：旧项目使用的是 App Pay 订单串，当前后端提供的是支付宝网页支付地址，两套协议不能混用。若后续切换 App Pay，需要后端改为生成 `alipay.trade.app.pay` 订单串，再接入原生 SDK。
- 旧项目的宽泛存储、电话和定位权限：当前业务不需要，不申请多余系统权限。

## 支付配置归属

支付宝 App ID、应用私钥、支付宝公钥、异步通知地址和同步返回地址仍由后端环境变量管理。移动端只接收支付订单结果，不保存支付私钥。
