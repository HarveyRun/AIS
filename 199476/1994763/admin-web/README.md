# 事先问管理后台

这是独立于手机端的管理后台工程，默认运行在 `http://localhost:5174`。源码按接口、布局和业务页面拆分，管理端不读取手机端本地数据。

## 启动

先启动根目录下的 Java 后端，再在本目录执行：

```powershell
npm install
npm run dev
```

首次打开会进入“创建首位管理员”。使用手机号和密码初始化，初始化操作只能成功一次，不存在默认管理员密码。

## 目录

- `src/api/`：管理接口与登录凭证
- `src/app/`：管理端路由
- `src/components/layout/`：全局后台布局和导航
- `src/pages/`：按业务拆分的管理页面
- `src/styles/`：全局基础样式

## 已有模块

- 数据概览
- 用户管理及账号停用/恢复
- 身份、岗位、经历认证审核及材料查看
- 询问与冻结资金状态查询
- 提现成功确认及失败退款
- 投诉反馈处理
- 商务合作处理
- 管理员操作审计

管理端开发请求通过 Vite 的 `/api` 和 `/uploads` 代理访问 Java 后端。生产部署时，应由网关将相同路径转发到后端，并使用 HTTPS。
